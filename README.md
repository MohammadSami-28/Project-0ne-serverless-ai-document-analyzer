
# Serverless AI Document Analyzer

An AI-powered serverless document processing application built using AWS and Generative AI.

## Project Overview

The application allows users to upload PDF documents and automatically extract, analyze, and summarize document content using AWS AI services.

## Technologies Used

- AWS Lambda
- Amazon S3
- Amazon Textract
- Amazon Bedrock
- Amazon API Gateway
- Amazon DynamoDB
- Python
- Terraform
- GitHub Actions

## Architecture

S3 → Lambda → Textract → Amazon Bedrock → DynamoDB → API Gateway → Frontend

## Key Features

- PDF document upload
- Automatic text extraction
- AI-powered document summarization
- Document question answering
- Serverless architecture
- Infrastructure as Code using Terraform
- CI/CD automation using GitHub Actions
